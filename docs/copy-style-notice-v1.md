# 문안 표기 규칙 v1 (2026-09-23)

환자·보호자가 읽는 **게시용 안내 문안**의 표기와 문장 기준. 날짜·시간·장소를 어떻게 적는가,
어떤 어미로 끝내는가를 한 곳에서 정한다.

> **적용 범위**: 원내 게시물(공지문·안내문), 뉴스레터, 배부물의 **본문 문안**. 화면 UI 라벨과
> 법무·동의서·약관·가격 고지는 **대상이 아니다**(그쪽은 문구 하나가 계약이라 문체 기준으로
> 손대지 않는다). 판정 단위는 문서가 아니라 **문안**이다 — 한 인쇄물 안에 규칙 대상인 안내
> 문장과 대상 밖인 고지 문구가 함께 있을 수 있다.

> **이 문서가 단일 출처(SoT)다.** 코드 소비처는 문서를 읽어 자기 코드 안 상수로 **복제**하고,
> 복제본이 갈리면 이 문서가 우선이며, 소비처의 하니스가 문서 끝 JSON 블록과 **id·rule 문자열
> 일치**를 검사한다. 규칙을 고치면 **문서 → JSON 블록 → 소비처 상수** 세 곳이 한 묶음이다.
> **현재 코드 소비처는 없다** — 첫 소비처였던 hub "AI 다듬기"는 2026-09-23 철거됐다(실사용 뒤
> 효용이 크지 않다는 사용자 판단). 지금은 사람이 문안을 쓸 때 보는 기준으로만 쓰인다.

> **왜 문서가 정본인가**: 공지문·뉴스레터·안내문이 같은 표기를 써야 하는데, 각 도구의
> 프롬프트 안에 규칙을 흩어 두면 앱마다 조용히 갈린다. 표기는 디자인 시스템의 일부다
> (색·간격과 같은 층위).

---

## 1. 불변 원칙 — 가장 먼저 지킨다

**사실과 의미를 바꾸지 않는다.** 표기와 문장의 결만 다듬는다.

손대지 않는 것:

- **숫자·날짜·시간·장소·대상·조건·연락처** — 값 자체
- **의무의 강도** — 가능(`~할 수 있습니다`)·필수·권장·금지를 서로 바꾸지 않는다
- **의료 지시의 내용** — 무엇을 하라고 했는지. 어미와 표기만 고친다
- **원문에 없는 정보** — 요일·연도·시간을 계산해 채워 넣지 않는다

이 원칙은 나머지 열네 줄보다 **위에 있다.** 표기 규칙을 지키려다 사실이 바뀌면 규칙을
포기하고 원문을 둔다.

> 기계가 쓰는 경우(LLM 다듬기 등)에는 이 절이 프롬프트의 **첫 규칙**이 되어야 하고,
> 소비처는 결과를 사람이 **비교해 보고 적용**하게 만든다. 표기 준수는 프롬프트로 유도하고,
> 출력 상한 같은 기계적 제약은 코드로 검사한다.

## 2. 표기 규칙

| 항목 | 기준 | 보기 | 비고 |
|---|---|---|---|
| **불변 원칙** | 숫자·날짜·시간·장소·대상·조건·연락처, 의무 표현(가능·필수·권장·금지), 의료 지시의 내용은 바꾸지 않는다 | "문진표 지참"은 남기고 어미만 바꿈 | §1. 모든 규칙에 우선한다 |
| **날짜** | `9월 29일(화)`. 월·일은 한글, 요일은 **괄호를 붙여** 쓴다. 연도는 해가 다를 때만 `2027년 1월 5일(화)` | `26.9. 29(화)` → `9월 29일(화)` | 괄호 붙여 쓰기는 문장부호 규정과 기존 인쇄 도구 관행 |
| **기간** | `9월 29일(화) ~ 10월 1일(목)`. 물결표 양쪽 한 칸, 양 끝에 요일 | `~ 10.1(목)` → `~ 10월 1일(목)` | 같은 달이어도 뒤쪽 월을 생략하지 않는다 |
| **시간** | `오후 1시 30분 ~ 2시`. 오전·오후는 한글, 시와 분 사이 한 칸, 정시는 `2시` | `오후1시30~2시` → `오후 1시 30분 ~ 2시` | 정오·자정은 `낮 12시`·`밤 12시`. 24시간제·AM/PM 표기는 쓰지 않는다 |
| **추정 금지** | 원문에 없는 요일·연도·시간을 만들어 넣지 않는다 | `10.1`에 요일이 없으면 `10월 1일`까지만 | 요일을 계산해 붙이면 틀릴 수 있고, 틀린 요일은 게시물에서 가장 나쁜 오류다 |
| **장소·층** | `병실 201호 (2층)`. 층은 한글 | `(2F)` → `(2층)` | 부가 정보 괄호는 앞말과 **한 칸 띄운다**(요일 괄호와 구분된다) |
| **항목 라벨** | `날짜:` 처럼 콜론을 붙이고 뒤에 한 칸 | `날짜 :` → `날짜:` | |
| **문장 종결** | 존댓말로 통일. 요청·지시는 `~해 주세요`, 사실은 `~입니다`, 가능은 `~할 수 있습니다` | `맞으세요` → `접종해 주세요` | **지시를 가능으로, 가능을 지시로 바꾸지 않는다**(§1). 구어체 명령형은 쓰지 않는다 |
| **강조** | `꼭!` 같은 감탄·기호 대신 `반드시 ~해 주세요`를 문장 안에 | `꼭! 지참하고` → `반드시 지참해 주세요` | 느낌표와 이모지는 쓰지 않는다 |
| **조건문** | 조건은 `~시(時)` 한자어 대신 **우리말 연결어**로. **조건의 내용과 대안의 의무 강도는 그대로 둔다** | `안되실 시` → `접종이 어려우면`<br>`발열 시` → `열이 나면` | ⚠ 특정 표현을 고정하지 않는다. `어려우면`은 어려움이 조건일 때의 보기일 뿐이고, 원문의 조건이 무엇인지에 따라 연결어가 달라진다. 서술어도 고정하지 않는다 — 원문이 지시면 `~해 주세요`로 남긴다(§1. 2026-09-23 실측: 서술어를 `~할 수 있습니다`로 지정했더니 `맞으세요`가 `접종하실 수 있습니다`로 바뀌어 의무 강도가 내려갔다) |
| **영문·약어** | `PM`·`2F`·`Tel` 같은 영문 약어는 한글로 | `2F` → `2층` | 고유명사(Wi-Fi 등)는 예외 |
| **숫자·단위** | 아라비아 숫자, 단위는 붙여 쓴다 | `3일간`·`201호` | |
| **중복 정보** | 같은 뜻의 반복이라도 **지우지 않는다**. 표기만 고친다 | `[3일간]` → `, 3일간` | 사실 삭제와 경계가 흐리다. 지우는 판단은 사람이 한다 |
| **줄과 길이** | 한 줄에 한 문장. 도구가 정한 줄 수·줄당 글자 상한 안에서 | | 상한은 도구마다 다르므로 소비처가 값을 넘긴다 |
| **어조** | 디자인 시스템 보이스(전문성·따뜻함·길잡이). 과장·유행어 없이 명료하게 | | 보이스 정본 = `docs/notes.md` |

## 3. 적용 보기

같은 내용을 규칙 전후로 쓴 것. 값(날짜·시간·장소·횟수)은 하나도 바뀌지 않았다.

**규칙 전**

```
날짜 : 26.9. 29(화)~ 10.1(목) [3일간]
시간 : 오후 1시30분~2시
장소 : 병실 201호 (2F)

해당 날짜에 안되실 시 10.13(화) 오후1시30~2시에 맞으세요.
꼭! 작성된 예방접종 문진표 지참하고 접종하러 가시면 됩니다.
```

**규칙 후**

```
날짜: 9월 29일(화) ~ 10월 1일(목), 3일간
시간: 오후 1시 30분 ~ 2시
장소: 병실 201호 (2층)

위 일정에 접종이 어려우면 10월 13일(화) 오후 1시 30분 ~ 2시에 접종해 주세요.
접종 시 미리 작성한 예방접종 문진표를 반드시 지참해 주세요.
```

`[3일간]`은 날짜로 드러나는 정보지만 **지우지 않았다**(중복 정보 규칙). `맞으세요`는
`접종해 주세요`가 되었고 `접종이 가능합니다`가 되지 않았다 — 지시를 가능으로 낮추면 의무의
강도가 바뀐다(불변 원칙).
