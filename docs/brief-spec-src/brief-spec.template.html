2.

색 사용 규칙

읽힘 기준"명암 차이"는 글자 색과 배경 색의 밝기 비율입니다. 같은 색이면 1, 검정과 흰색이면 21 입니다. 숫자가 클수록 잘 읽힙니다. 4.5 는 일반 글자를 읽기에 충분하다고 보는 국제 웹 접근성 기준(WCAG AA)의 값이고, 아이콘과 테두리는 3.0 이면 됩니다.

4.5이상
글자와 배경의 명암 차이 하한. 흰 배경 기준으로 본문 #4A605C 는 6.7, 보조 글자 #5A6F6B 는 5.4, 링크 글자 #167565 는 5.6.
3.0이상
아이콘과 테두리의 하한. 포포 틸 #1D9581 은 흰 배경에서 3.7이라 아이콘과 강조면에만 쓰고, 링크 글자와 강조 버튼 배경에는 진한 틸 #167565 를 씁니다.

이렇게

  • 여기 안내된 색만 씁니다.
  • 제목은 진한 색 #1E3131, 본문은 중간 색 #4A605C 로 구분합니다.
  • 채움 버튼(공식·강조)은 한 화면에 하나. 나머지는 부드러운 버튼이나 테두리 버튼으로 둡니다.
  • 어두운 배경(마리아 그린) 위에는 아이보리 글자를 씁니다.
  • 포포 틸 #1D9581 은 눈에 띄어야 하는 곳에만 포인트로 씁니다.
  • 링크 글자와 강조 버튼 배경에는 진한 틸 #167565 를 씁니다.

이렇게는 안 됩니다

  • 가이드에 없는 색을 임의로 만들기.
  • 마리아 그린 배경 위에 포포 틸 글자.
  • 포포 틸과 마리아 핑크를 한 화면에서 동시에 버튼으로.
  • 연한 배경색(아이보리, 연한 그린)을 글자색으로.
  • 옛 보조 색 #7E9897 을 글자색으로. 보조 정보는 #5A6F6B.
  • 포포 틸 위에 글자를 얹거나, 포포 틸을 글자색으로.
  • 포포 틸을 배경 전체에 깔기.

스타일 (화면)

모서리버튼, 입력칸, 배지는 8px 이 기본입니다. 카드와 패널, 다이얼로그는 12px, 대형 카드는 16px. 7px 이나 10px 같은 중간값은 만들지 않습니다. 캡슐형은 누를 수 있는 요소(칩, 아바타, 진행 단계)에만 씁니다.
그림자세 단계만 씁니다. 떠 있는 층일수록 진합니다(견본은 축소 예시). 장식으로 그림자나 그라데이션을 얹지 않습니다. 카드의 경계는 그림자가 아니라 1px 테두리로 둡니다.
1632
간격과 테두리요소 사이 여백은 4px 배수(4, 8, 12, 16, 24…)로만 둡니다. 테두리는 1px 이 기본이고 강조가 필요할 때만 2px. 선과 상자를 늘리지 않고 간격으로 나눕니다.
