# Any other notes — 마리아의료재단 디자인 시스템

## 타깃 사용자
- 본 디자인 시스템의 **1차 사용자는 개발자·디자이너가 아닌 각 분원 원무과 실무자**입니다.
- 따라서 "어떤 상황에 어떤 색을 쓰는가"를 예시 중심으로 안내합니다. 전문용어(primary/secondary 등 시맨틱 토큰 명칭)는 최소화하고, "제목/본문/보조/링크"처럼 목적 중심 이름을 씁니다.
- 2차 사용자: 브랜드전략부, 외주 디자이너, 향후 확장될 웹/앱 개발팀.

## 주요 산출물
- **마케팅·커뮤니케이션 머티리얼이 UI보다 큰 비중**: PPT 슬라이드, 원내 포스터·안내문, 이벤트 배너, 카카오톡/인스타그램 카드, 브로슈어.
- 인쇄 산출물 비중이 크므로 CMYK 변환·인쇄 테스트 전제를 항상 고려해주세요.
- 웹/앱 UI는 향후 확장 영역: 마리아병원 공식 사이트(mariababy.com), 환자용 앱, 사내 툴.

## 컬러 구조
- **4 코어**: 마리아 그린 `#1E3131` / 포포 틸 `#1D9581` / 마리아 핑크 `#E0A793` / 마리아 아이보리 `#F4EEED`
- 각 코어는 밝기 스케일을 가지며 역할에 매핑됩니다 (text primary/body/muted, 배경, 버튼, 상태).
- **포포 틸은 마스코트 캐릭터 POPO에서 추출한 색상**입니다. 실무에서 이미 사용하던 색을 v2.1에서 공식화했습니다.

## 타이포그래피
- Primary: **Pretendard**. 한/영 모두 커버. Fallback: -apple-system, BlinkMacSystemFont.
- 계층: 제목(#1E3131) > 본문(#4A605C) > 보조(#7E9897).
- 보조 색상(#7E9897)은 14px 이상 굵은 글씨에서만 사용 (가독성 확보).

## 버튼 4단계
1. **공식 버튼** — 마리아 그린 배경 + 흰 글자. 진료 예약·문의처럼 격식 있는 행동.
2. **강조 버튼** — 포포 틸 배경 + 흰 글자. 눈에 띄어야 하는 CTA (온라인 예약, 이벤트 신청).
3. **부드러운 버튼** — 마리아 핑크 배경 + 마리아 그린 글자. 보조 행동.
4. **테두리 버튼** — 흰 배경 + 마리아 그린 테두리. 가벼운 링크.
- 한 페이지에 강조 버튼은 1~2개만.

## 꼭 지켜야 하는 규칙
- 가이드에 없는 색상을 임의로 만들지 않습니다.
- 마리아 그린 배경 위에 포포 틸 글자 금지 (명도 대비 불충족).
- 포포 틸과 마리아 핑크를 한 페이지 버튼으로 동시 사용 금지.
- 포포 틸은 배경 전체가 아닌 포인트로만 사용.
- 연한 배경색(아이보리, 연한 그린)을 글자색으로 사용 금지.

## 브랜드 철학
- **경영 이념**: "마리아병원은 오직 난임 부부를 위해서만 존재합니다."
- **세 가지 가치**
  - **PRIDE** — 끊임없는 연구와 전문성 (1989년부터 축적한 난임 전문 노하우)
  - **SIMPLE** — 난임 환자만을 위한 간편한 진료 시스템 (불필요한 검사·주사 최소화)
  - **TRUTH** — 전인적 치료를 위한 서비스 (몸과 마음까지 케어)
- **3S 서비스 원칙** — Sincerity(정성) · Speed(신속) · Smile(미소)
- **슬로건**: "Make Miracles" / "건강한 가족을 만드는 것"

## 톤 & 매너
- 보이스: **전문성 + 따뜻함 + 길잡이**. 신뢰감 있는 의료기관 이미지를 유지하되, 난임 가족을 향한 정서적 배려를 담은 부드러운 결. 환자를 "안내받는 사람"이 아니라 "함께 걸어가는 동행자"로 대함.
- **핵심 메시지 패턴**: "엄마가 되고 싶은 간절함이 축복과 기쁨으로 이어지도록, 마리아병원이 당신의 길잡이가 되겠습니다." — "길잡이", "함께", "동행" 같은 동반자적 언어가 핵심.
- **환영하는 표현**: "축하드립니다", "함께하겠습니다", "도와드립니다", "곁에 있겠습니다", "응원합니다".
- **지양하는 표현**: 과도한 이모지, 경쾌한 유행어, 의료 광고 특유의 과장된 수사, 시술 성공만을 강조하는 결과 중심 카피. 의료·건강 정보 특성상 오해 여지 없는 명료한 문장을 우선.
- **정서적 민감도**: 난임은 신체적·정신적으로 힘든 과정. "실패", "부족" 같은 부정형 단어는 가능한 피하고, "아직 만나지 못한", "다시 시작하는" 같은 중립·긍정 표현을 선호.

## 본 시스템의 성격
- 본 가이드는 **"이렇게만 만들어야 한다"가 아니라 참고용**입니다. 각 상황·매체에 따라 유연하게 응용 가능하며, 자주 쓰는 조합을 정리한 것입니다.
- 새 매체·디자인 확장 시 이 토큰을 베이스로 두고 조합을 확장합니다.
